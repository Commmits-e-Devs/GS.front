# GS Front

Repositório com projetos e práticas de desenvolvimento front-end, utilizando HTML, CSS e JavaScript.

---

## Descrição

Projeto voltado ao desenvolvimento de interfaces web, com foco em estruturação de páginas, estilização e interação com o usuário.

Reúne atividades práticas aplicadas durante o processo de aprendizado em front-end.

---

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

---

## Estrutura do projeto

```bash id="k3d9x2"
GS.front/
│
├── index.html
├── style.css
├── script.js
└── assets/
```

---

## Conteúdo abordado

* Estruturação de páginas web
* Estilização com CSS
* Responsividade básica
* Manipulação do DOM
* Eventos em JavaScript
* Lógica de interação com o usuário

## Como executar

Clone o repositório:

```bash id="p8m1qz"

```

